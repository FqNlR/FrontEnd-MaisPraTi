# Portfólio Pessoal

Este projeto é uma landing page criada para apresentar informações sobre mim, meus conhecimentos e alguns dos meus projetos publicados no GitHub.

A página foi desenvolvida como atividade do curso Dev Full Stack Jr +PraTi, utilizando HTML, CSS e JavaScript.

## Funcionalidades

- Apresentação pessoal
- Consumo da API REST do GitHub para exibir projetos públicos
- Formulário simples de contato com mensagem de confirmação após envio
- Layout responsivo para dispositivos móveis.
